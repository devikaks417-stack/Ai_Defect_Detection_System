Model Architecture & Specifications

Technical documentation of the PatchCore industrial visual anomaly detection pipeline.

1. PatchCore Methodology

PROMETHEUS-X utilizes the PatchCore memory-bank inspection architecture. Unlike conventional supervised classifiers that require hundreds of defective examples, PatchCore is an unsupervised anomaly detection framework trained strictly on nominal (good) images.

2. Frozen ResNet-50 Backbone

A frozen ResNet-50 pretrained on ImageNet extracts multi-scale visual features from intermediate convolutional blocks: Layer 2 (edges & wire boundaries) and Layer 3 (bundle context), concatenated into 1536-dimensional patch representations.

3. Coreset Memory Bank Subsampling

The full nominal patch memory bank (223,440 vectors) is compressed via a memory-efficient greedy coreset selection algorithm to 10% representation (22,344 vectors), enabling inference latency under 120ms on RTX 3050 GPUs.

4. Statistical Threshold Calibration

The factory decision threshold is calibrated to 23.4457 using a rigorous statistical envelope (μ + 3σ) derived from 30 holdout nominal validation samples, ensuring ultra-low false alarm rates (<1.05%).

About PROMETHEUS-X

Open-Set Vision AI for Industrial Quality Assurance.

Product Mission

PROMETHEUS-X is an industrial AI visual inspection platform designed to assist automotive quality engineers in identifying assembly errors, missing clamps, unclipped fastening wires, and foreign object debris (FOD) during component assembly.
